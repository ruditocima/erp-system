Panduan Integrasi Supabase (Free Tier) & GitHub Pages

Langkah mudah menghubungkan HTML Frontend ini ke database cloud Supabase gratis dan deploy ke GitHub.

1. Buat Tabel di Supabase SQL Editor

-- Tabel Barang
CREATE TABLE master_barang (
    id SERIAL PRIMARY KEY,
    kode VARCHAR(50) UNIQUE NOT NULL,
    nama VARCHAR(150) NOT NULL,
    kategori VARCHAR(100),
    jenis VARCHAR(100)
);

-- Tabel Gudang
CREATE TABLE master_gudang (
    id SERIAL PRIMARY KEY,
    kode VARCHAR(50) UNIQUE NOT NULL,
    nama VARCHAR(150) NOT NULL,
    tipe VARCHAR(50) NOT NULL, -- 'Perusahaan Sendiri' atau 'Pihak Lain'
    lokasi TEXT,
    pic VARCHAR(100)
);

-- Tabel Project
CREATE TABLE master_project (
    id SERIAL PRIMARY KEY,
    kode_project VARCHAR(50) UNIQUE NOT NULL,
    periode VARCHAR(50),
    type VARCHAR(100),
    region VARCHAR(100),
    no_pr_po VARCHAR(100),
    po_plan VARCHAR(50),
    po_final VARCHAR(50),
    status_po VARCHAR(50),
    permit VARCHAR(50),
    status_snd VARCHAR(50),
    status_project VARCHAR(50),
    status_doc VARCHAR(50)
);

2. Integrasi ke Script HTML (JavaScript)

Tambahkan CDN Supabase di bagian <head> dan inisialisasi:

<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
<script>
  const SUPABASE_URL = 'https://your-project.supabase.co';
  const SUPABASE_KEY = 'your-anon-key';
  const supabaseClient = supabase.createClient(SUPABASE_URL, SUPABASE_KEY);
</script>

3. Hosting Gratis di GitHub Pages

  • Simpan file ini dengan nama index.html dalam sebuah repository GitHub.
  • Masuk ke menu Settings repository > Pages.
  • Pilih branch main / root, lalu klik Save.
  • Aplikasi WMS Anda siap diakses secara online melalui URL GitHub Pages!
